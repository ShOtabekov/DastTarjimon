## About the Project

**Dast Tarjimon** is a social technology initiative from Tajikistan exploring the use of Artificial Intelligence (AI) and computer vision to support communication for people with hearing impairments.

The project aims to develop an accessible digital tool that can recognize hand gestures through a device camera and convert validated gestures into text and, in future versions, speech.

Our long-term vision is to contribute to more inclusive communication, education, and access to everyday services in Tajikistan.

## The Problem

People with hearing impairments may face communication barriers in education, healthcare, public services, employment, and everyday social interactions.

Access to affordable and locally relevant assistive technologies remains an important challenge.

Dast Tarjimon aims to explore how modern AI technologies can help address these barriers, with a focus on local needs and community participation.

## Current Prototype

The project is currently at an early prototype stage.

The existing prototype includes:

- Real-time camera access.
- Hand detection using MediaPipe.
- Hand landmark tracking.
- Experimental recognition of a limited set of basic hand gestures.
- Display of recognized gesture labels.
- Text-to-speech functionality using browser speech synthesis where supported.

**Important:** The current gesture labels are experimental demonstrations. They are not yet a validated translation system for Tajik Sign Language.

## Project Goals

1. Develop a reliable hand gesture recognition system.
2. Research and document locally used sign language gestures with community participation.
3. Build a validated dataset with appropriate consent and privacy safeguards.
4. Improve recognition accuracy using computer vision and machine learning.
5. Support text and speech output.
6. Develop an accessible and mobile-friendly interface.
7. Conduct pilot testing with people with hearing impairments.
8. Explore opportunities for scaling the solution across Tajikistan and Central Asia.

## Getting Started

### Requirements

- Node.js (LTS recommended)
- npm
- Git
- A modern web browser
- A camera-enabled device

### Installation

Clone the repository:

```bash
git clone https://github.com/ShOtabekov/dast-tarjimon.git
```

Navigate to the project directory:

```bash
cd dast-tarjimon
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local address displayed in the terminal.

### Production Build

```bash
npm run build
```
